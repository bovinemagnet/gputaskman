# Rust TUI (milestone 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `gputaskman` with no `--once`/`--json` opens a live ratatui TUI with the same behaviour as the Python Textual UI on native Linux.

**Architecture:** A new platform-neutral library crate `rust/crates/gputaskman-tui`. Pure state (`App`), pure actions (`action.rs`), pure line builders per screen part (`view/*`), one `view::draw` that lays them out and records hit areas, a sampler thread that owns the collectors, and a terminal guard. The binary builds one `Collector` per GPU and calls `gputaskman_tui::run`.

**Tech Stack:** Rust 1.97.0 (edition 2024), ratatui 0.30.2 (crossterm 0.29 backend), crossterm 0.29.0, insta 1.49.0 (dev only), the existing `gputaskman-core` crate.

**Spec:** `docs/superpowers/specs/2026-11-09-rust-tui-design.md` (read it first; it is binding). The Python reference is `src/gputaskman/app.py` and its tests in `tests/test_core.py` (`ChartTests`, `UiTests`).

## Global Constraints

- Toolchain 1.97.0 (pinned in `rust/rust-toolchain.toml`); edition 2024; workspace lints (`unwrap_used` and `expect_used` denied) apply to the new crate. Test files start with `#![allow(clippy::unwrap_used, clippy::expect_used)]`.
- New dependencies, exact versions: `ratatui = "0.30.2"`, `crossterm = "0.29.0"`; dev-only `insta = "1.49.0"`. No other new crates.
- The TUI crate does not depend on `gputaskman-linux`; it builds and tests on Ubuntu, Windows and macOS CI.
- The AGENTS.md provenance rules bind every screen element: only `Measured` bytes are summed (through `MeasuredTotal`); unknown is `n/a` or blank, never 0; markers `*`/`?` come from `vram_label`.
- The UI never reads `/proc`, `/sys`, NVML or the network itself; everything it shows comes from `Snapshot` (and the `LlmView` inside its rows).
- Python stays unchanged as the reference.
- Documentation uses British spelling. Author Paul Snow; version 0.0.0. Never mention AI assistance in commits, comments or docs.
- All commands run from `rust/`. Run `cargo fmt --all` before every commit; `cargo clippy --workspace --all-targets -- -D warnings` must stay clean.

## Rulings made while planning (the spec leaves these open)

- **R1 Table wheel:** the mouse wheel over the table moves the selection one row per notch (which scrolls the table); over the dashboard, inspector and help it scrolls by 3 rows.
- **R2 Auto-select:** the first LLM row is selected on the first snapshot that has one, and only while nothing is selected (so it never steals a user's choice).
- **R3 Selection outside the filter:** a selected row hidden by the top filter counts as disappeared (selection cleared).
- **R4 Paged column:** blank whenever the row has no committed counter (`committed` is `not_on_backend`, true on every Linux backend), because `paged_out()` would otherwise borrow the VRAM row's reason and print `n/a` where Python prints nothing.
- **R5 Inspector spill:** the inspector header prints `spill(RAM) n/a` for rows without a spill counter (Python's text), while the table leaves that cell blank.
- **R6 Wrapped heights:** ratatui's `unstable-rendered-line-info` feature is enabled for `Paragraph::line_count` (a feature, not a new crate).
- **R7 Sources:** `run` and `Sampler::spawn` take `Vec<Box<dyn Source>>` (a trait `Collector` implements) instead of `Vec<Collector>`, so the sampler is tested with fakes; they also take the 0.5 s warm-up explicitly.

```rust
/// Python's `KIND_STYLE`; kinds it does not list are unstyled.
pub fn kind_style(kind: &str) -> Style {
    let c = |i: u8| fg(Color::Indexed(i));
    match kind {
        "LLM" => fg(MAGENTA).add_modifier(Modifier::BOLD),
        "decision" => c(170).add_modifier(Modifier::BOLD),
        "decision?" | "diffusion" => c(170),
        "embedding" => c(183),
        "speech" => c(153),
        "AI" => c(141),
        "compute" => c(172),

        "video" => fg(YELLOW),

/// One byte value as text: blank when the backend has no such counter, `n/a` when it has one but
/// this value is unknown, otherwise the size with what kind of number it is.
pub fn bytes_text(b: &Bytes) -> String {
    match *b {
        Bytes::Measured { bytes } => gb(bytes as f64),
        Bytes::Inferred { bytes, by } => format!("{}{}", gb(bytes as f64), by.marker()),
        Bytes::Estimated { bytes, .. } => format!("{} (est)", gb(bytes as f64)),
        Bytes::Reported { bytes, .. } => format!("{} (reported)", gb(bytes as f64)),
        Bytes::Unavailable {
            reason: Reason::NotOnBackend,
        } => String::new(),
        Bytes::Unavailable { .. } => "n/a".to_string(),
    }
}

/// A table cell: as `bytes_text`, but a measured value under `floor` is blank (Python hides tiny
/// spill and paged values).
pub fn bytes_cell(b: &Bytes, floor: u64) -> String {
    match *b {
        Bytes::Measured { bytes } if bytes < floor => String::new(),
        _ => bytes_text(b),
    }
}

/// A percentage cell: `n/a` (grey) when unknown, blank below 0.5, bold from 20.
pub fn pct_cell(v: Option<f64>) -> (String, Style) {
    match v {
        None => ("n/a".to_string(), fg(GREY62)),
        Some(v) if v < 0.5 => (String::new(), Style::new()),
        Some(v) => (
            format!("{v:.0}"),
            if v >= 20.0 { bold() } else { Style::new() },
        ),
    }
}

/// `4096` as `4,096` (Python's `{:,}`).
pub fn thousands(n: u64) -> String {
    let digits = n.to_string();
    let mut out = String::new();
    for (i, c) in digits.chars().enumerate() {
        if i > 0 && (digits.len() - i) % 3 == 0 {
            out.push(',');
        }
        out.push(c);
    }
    out
}
```

```rust
//! Text widgets ported from `app.py`: the sparkline and the stacked bar.
use ratatui::style::{Color, Style};
use ratatui::text::Span;

use crate::format::GREY27;

const SPARK: [char; 8] = ['▁', '▂', '▃', '▄', '▅', '▆', '▇', '█'];

/// Python's `spark`: the last `width` values; a missing reading is a blank, zero is the lowest
/// bar, and values are clamped to `0..=top`.
pub fn spark(values: &[Option<f64>], width: usize, top: f64) -> String {
    let top = if top > 0.0 { top } else { 1.0 };
    let start = values.len().saturating_sub(width);
    values[start..]
        .iter()
        .map(|v| match v {
            None => ' ',
            Some(v) => {
                let level = (v / top * 7.0 + 0.5).trunc();
                let level = if level.is_nan() { 0.0 } else { level.clamp(0.0, 7.0) };
                SPARK[level as usize]
            }
        })
        .collect()
}

/// Python's `stacked_bar`: a `█` run per part in proportion to `total` (half-to-even rounding,
/// as Python's `round`), never more than `width` in all, then `░` for the rest.
pub fn stacked_bar(parts: &[(f64, Color)], total: f64, width: usize) -> Vec<Span<'static>> {
    let mut spans = Vec::new();
    let mut used = 0usize;
    for &(value, color) in parts {
        let n = if total > 0.0 {
            (value / total * width as f64).round_ties_even().max(0.0) as usize
        } else {
            0
        };
        let n = n.min(width - used);
        if n > 0 {
            spans.push(Span::styled("█".repeat(n), Style::new().fg(color)));
            used += n;
        }
    }
    if width > used {
        spans.push(Span::styled("░".repeat(width - used), Style::new().fg(GREY27)));
    }
    spans
}
```

```rust
pub fn is_amd(s: &Snapshot) -> bool {
    s.adapter.as_ref().is_some_and(|a| a.vendor_id == VENDOR_AMD)
}

/// One GPU's recent readings per chart. `None` is a missing reading (drawn blank), never 0.
#[derive(Debug, Clone, Default, PartialEq)]
pub struct History {
    series: [Vec<Option<f64>>; 8],
}

impl History {
    pub fn record(&mut self, s: &Snapshot) {
        let amd = is_amd(s);
        let d = s.device.as_ref();
        let read = |f: fn(&DeviceTelemetry) -> Option<f64>| d.and_then(f);
        let clock = d
            .and_then(|d| if amd { d.gfx_clock } else { d.sm_clock })
            .map(f64::from);
        let vram = match (s.vram_used.value(), s.vram_total.value()) {
            (Some(used), Some(total)) if total > 0 => Some(100.0 * used as f64 / total as f64),
            _ => None,
        };
        let values = [
            read(|d| d.util_gpu),
            clock,
            vram,
            read(|d| d.util_mem),
            read(|d| d.temp),
            read(|d| d.power_w),
            read(|d| d.enc),
            read(|d| d.dec),
        ];
        for (series, v) in self.series.iter_mut().zip(values) {
            series.push(v);
            if series.len() > CAPACITY {
                series.remove(0);
            }
        }
    }

    pub fn values(&self, c: Chart) -> &[Option<f64>] {
        &self.series[c as usize]
    }

    pub fn current(&self, c: Chart) -> Option<f64> {
        self.values(c).last().copied().flatten()
    }

    /// The top of the chart: 100 for percentages, 120 for °C; for clock and power the larger of
    /// the device's maximum and the highest reading kept, at least 1.
    pub fn scale(&self, c: Chart, device: Option<&DeviceTelemetry>) -> f64 {
        let seen = self.values(c).iter().flatten().copied().fold(0.0, f64::max);
        match c {
            Chart::Clock => device
                .and_then(|d| d.sm_clock_max)
                .map_or(0.0, f64::from)
                .max(seen)
                .max(1.0),
            Chart::Power => device
                .and_then(|d| d.power_limit_w)
                .unwrap_or(0.0)
                .max(seen)
                .max(1.0),
            Chart::Temperature => 120.0,
            _ => 100.0,
        }
    }
}
```

```rust
//! Which processes the table shows, in what order, and their keys (`app.py` `visible_rows`).
use std::cmp::Reverse;

use gputaskman_core::collector::{ProcRow, Snapshot};

use crate::format::MIB;

/// Sort names, cycled by `s`.
pub const SORTS: [&str; 5] = ["VRAM", "GPU%", "spill", "paged", "name"];

/// A row as the table shows it: with its snapshot and, when there are several GPUs, its GPU.
#[derive(Debug, Clone, Copy)]
pub struct ShownRow<'a> {
    pub row: &'a ProcRow,
    pub snap: &'a Snapshot,
    pub gpu: Option<usize>,
}

impl ShownRow<'_> {
    /// `ProcRow::key()`, prefixed `<gpu>:` when there are several GPUs.
    pub fn key(&self) -> String {
        match self.gpu {
            Some(i) => format!("{i}:{}", self.row.key()),
            None => self.row.key(),
        }
    }
}

fn shown(r: &ProcRow) -> u64 {
    r.gpu.shown_vram().map_or(0, |s| s.get())
}

fn busiest(r: &ProcRow) -> f64 {
    r.gpu.engines.busiest().unwrap_or(0.0)
}

fn spill(r: &ProcRow) -> u64 {
    r.gpu.shared.value().unwrap_or(0)
}

fn paged(r: &ProcRow) -> u64 {
    r.gpu.paged_out().value().unwrap_or(0)
}

/// Python's "top" filter: unknown VRAM, real VRAM, load, spill, paging or an LLM view keeps a row.
pub fn in_top(r: &ProcRow) -> bool {
    !r.gpu.vram.is_measured()
        || shown(r) >= 32 * MIB
        || busiest(r) >= 1.0
        || spill(r) >= 64 * MIB
        || paged(r) >= 128 * MIB
        || r.llm.is_some()
}

/// Stable sort by `SORTS[sort]`: largest first, names A to Z; unknown values count as 0.
pub fn sort_rows(rows: &mut [ShownRow<'_>], sort: usize) {
    match sort % SORTS.len() {
        0 => rows.sort_by_key(|r| Reverse(shown(r.row))),
        1 => rows.sort_by(|a, b| busiest(b.row).total_cmp(&busiest(a.row))),
        2 => rows.sort_by_key(|r| Reverse(spill(r.row))),
        3 => rows.sort_by_key(|r| Reverse(paged(r.row))),
        _ => rows.sort_by_key(|r| r.row.name.to_lowercase()),
    }
}

/// The table's rows over every snapshot, tagged with their GPU when there are several.
pub fn table_rows(snaps: &[Snapshot], show_all: bool, sort: usize) -> Vec<ShownRow<'_>> {
    let multi = snaps.len() > 1;
    let mut rows: Vec<ShownRow<'_>> = snaps
        .iter()
        .enumerate()
        .flat_map(|(i, snap)| {
            snap.procs
                .iter()
                .filter(move |r| show_all || in_top(r))
                .map(move |row| ShownRow {
                    row,
                    snap,
                    gpu: multi.then_some(i),
                })
        })
        .collect();
    sort_rows(&mut rows, sort);
    rows
}

/// The largest LLM row on any GPU (Python's one-time auto-selection).
pub fn first_llm_key(snaps: &[Snapshot]) -> Option<String> {
    table_rows(snaps, true, 0)
        .into_iter()
        .find(|r| r.row.llm.is_some())
        .map(|r| r.key())
```

```rust
#[derive(Debug, Default)]
pub struct App {
    pub snapshots: Vec<Snapshot>,
    /// One per GPU index ever seen.
    pub histories: Vec<History>,
    /// The selected row's `ShownRow::key()`.
    pub selected: Option<String>,
    /// The table position navigation starts from; follows the selection while there is one.
    pub cursor: usize,
    pub sort: usize,
    pub show_all: bool,
    pub paused: bool,
    pub slim: bool,
    /// `None` shows all charts.
    pub chart: Option<Chart>,
    pub popup: Popup,
    pub dashboard_scroll: u16,
    pub inspector_scroll: u16,
    pub areas: Areas,
    pub quit: bool,
    /// Set once an LLM has been auto-selected or the user has chosen a row.
    auto_selected: bool,
}

impl App {
    pub fn multi(&self) -> bool {
        self.snapshots.len() > 1
    }

    /// The table's rows, filtered and sorted as shown.
    pub fn rows(&self) -> Vec<ShownRow<'_>> {
        rows::table_rows(&self.snapshots, self.show_all, self.sort)
    }

    pub fn selected_row(&self) -> Option<ShownRow<'_>> {
        let key = self.selected.as_deref()?;
        self.rows().into_iter().find(|r| r.key() == key)
    }

    /// Takes one refresh: a snapshot per GPU, in GPU order.
    pub fn apply_all(&mut self, snaps: Vec<Snapshot>) {
        if snaps.is_empty() {
            return;
        }
        let multi = snaps.len() > 1;
        if !self.snapshots.is_empty() && multi != self.multi() {
            self.selected = self.selected.take().and_then(|k| {
                if multi {
                    Some(format!("0:{k}"))
                } else {
                    k.strip_prefix("0:").map(String::from)
                }
            });
        }
        if self.histories.len() < snaps.len() {
            self.histories.resize_with(snaps.len(), History::default);
        }
        for (history, snap) in self.histories.iter_mut().zip(&snaps) {
            history.record(snap);
        }
        self.snapshots = snaps;
        // Ruling R2: the first LLM is selected once, and never over a user's choice.
        if self.selected.is_none()
            && !self.auto_selected
            && let Some(key) = rows::first_llm_key(&self.snapshots)
        {
            self.selected = Some(key);
        }
        if self.selected.is_some() {
            self.auto_selected = true;
        }
        self.sync_selection();
    }

    /// Keeps `cursor` on the selected row, or clears a selection whose row is gone (ruling R3).
    pub(crate) fn sync_selection(&mut self) {
        let (found, n) = {
            let rows = self.rows();
            let found = self
                .selected
                .as_deref()
                .map(|k| rows.iter().position(|r| r.key() == k));
            (found, rows.len())
        };
        match found {
            Some(Some(i)) => self.cursor = i,
            Some(None) => self.selected = None,
            None => {}
        }
        self.cursor = self.cursor.min(n.saturating_sub(1));
    }
}
```

```rust
//! Input: keys and mouse events become `Action`s, and `App::update` applies them.
use ratatui::crossterm::event::{
    KeyCode, KeyEvent, KeyEventKind, KeyModifiers, MouseButton, MouseEvent, MouseEventKind,
};
use ratatui::layout::{Position, Rect};

use crate::app::{App, CHART_MODES, Popup, mode_index};
use crate::rows::SORTS;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Pane {
    Dashboard,
    Table,
    Inspector,
    Help,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Action {
    Quit,
    CycleSort,
    CycleChart,
    ToggleAll,
    ToggleSlim,
    TogglePause,
    Help,
    ClosePopup,
    Up,
    Down,
    PageUp,
    PageDown,
    Home,
    End,
    /// Select the table row at this index.
    Select(usize),
    OpenChartMenu,
    MenuMove(i32),
    MenuChoose,
    /// Choose `CHART_MODES[i]` directly (a click).
    MenuPick(usize),
    Scroll(Pane, i32),
}

/// Footer hints: key, label, action.
pub const FOOTER: [(&str, &str, Action); 7] = [
    ("q", "Quit", Action::Quit),
    ("s", "Sort", Action::CycleSort),
    ("c", "Chart", Action::CycleChart),
    ("a", "All/Top", Action::ToggleAll),
    ("m", "Slim/Full", Action::ToggleSlim),
    ("p", "Pause", Action::TogglePause),
    ("?", "Explain", Action::Help),
];

const MENU_LAST: i32 = CHART_MODES.len() as i32;

pub fn from_key(key: KeyEvent, app: &App) -> Option<Action> {
    if key.kind != KeyEventKind::Press {
        return None;
    }
    if key.modifiers.contains(KeyModifiers::CONTROL) && key.code == KeyCode::Char('c') {
        return Some(Action::Quit);
    }
    match app.popup {
        Popup::Help { .. } => match key.code {
            KeyCode::Esc | KeyCode::Char('q' | '?') => Some(Action::ClosePopup),
            KeyCode::Up => Some(Action::Scroll(Pane::Help, -1)),
            KeyCode::Down => Some(Action::Scroll(Pane::Help, 1)),
            KeyCode::PageUp => Some(Action::Scroll(Pane::Help, -10)),
            KeyCode::PageDown => Some(Action::Scroll(Pane::Help, 10)),
            _ => None,
        },
        Popup::ChartMenu { .. } => match key.code {
            KeyCode::Up => Some(Action::MenuMove(-1)),
            KeyCode::Down => Some(Action::MenuMove(1)),
            KeyCode::Home => Some(Action::MenuMove(-MENU_LAST)),
            KeyCode::End => Some(Action::MenuMove(MENU_LAST)),
            KeyCode::Enter => Some(Action::MenuChoose),
            KeyCode::Esc => Some(Action::ClosePopup),
            _ => None,
        },
        Popup::None => match key.code {
            KeyCode::Char('q') => Some(Action::Quit),
            KeyCode::Char('s') => Some(Action::CycleSort),
            KeyCode::Char('c') => Some(Action::CycleChart),
            KeyCode::Char('a') => Some(Action::ToggleAll),
            KeyCode::Char('m') => Some(Action::ToggleSlim),
            KeyCode::Char('p') => Some(Action::TogglePause),
            KeyCode::Char('?') => Some(Action::Help),
            KeyCode::Up => Some(Action::Up),
            KeyCode::Down => Some(Action::Down),
            KeyCode::PageUp => Some(Action::PageUp),
            KeyCode::PageDown => Some(Action::PageDown),
            KeyCode::Home => Some(Action::Home),
            KeyCode::End => Some(Action::End),
            _ => None,
        },
    }
}

pub fn from_mouse(m: MouseEvent, app: &App) -> Option<Action> {
    let at = |r: Rect| r.contains(Position::new(m.column, m.row));
    let a = &app.areas;
    match m.kind {
        MouseEventKind::ScrollDown | MouseEventKind::ScrollUp => {
            let sign = if m.kind == MouseEventKind::ScrollDown { 1 } else { -1 };
            if matches!(app.popup, Popup::Help { .. }) {
                Some(Action::Scroll(Pane::Help, 3 * sign))
            } else if at(a.table_body) {
                Some(Action::Scroll(Pane::Table, sign)) // ruling R1
            } else if at(a.inspector) {
                Some(Action::Scroll(Pane::Inspector, 3 * sign))
            } else if at(a.dashboard) {
                Some(Action::Scroll(Pane::Dashboard, 3 * sign))
            } else {
                None
            }
        }
        MouseEventKind::Down(MouseButton::Left) => match app.popup {
            Popup::Help { .. } => None,
            Popup::ChartMenu { .. } => {
                if at(a.chart_menu) {
                    let i = usize::from(m.row - a.chart_menu.y).checked_sub(1)?;
                    (i < CHART_MODES.len()).then_some(Action::MenuPick(i))
                } else {
                    Some(Action::ClosePopup)
                }
            }
            Popup::None => {
                if at(a.chart_selector) {
                    Some(Action::OpenChartMenu)
                } else if at(a.table_body) {
                    Some(Action::Select(
                        a.table_offset + usize::from(m.row - a.table_body.y),
                    ))
                } else {
                    FOOTER
                        .iter()
                        .zip(a.footer_hints)
                        .find(|(_, r)| at(*r))
                        .map(|((_, _, action), _)| *action)
                }
            }
        },
        _ => None,
    }
}

fn step(value: u16, delta: i32, max: u16) -> u16 {
    let v = i64::from(value) + i64::from(delta);
    u16::try_from(v.clamp(0, i64::from(max))).unwrap_or(max)
}

impl App {
    pub fn update(&mut self, action: Action) {
        let page = i32::from(self.areas.table_body.height.max(1));
        match action {
            Action::Quit => self.quit = true,
            Action::CycleSort => {
                self.sort = (self.sort + 1) % SORTS.len();
                self.sync_selection();
            }
            Action::CycleChart => {
                self.chart = CHART_MODES[(mode_index(self.chart) + 1) % CHART_MODES.len()];
            }
            Action::ToggleAll => {
                self.show_all = !self.show_all;
                self.sync_selection();
            }
            Action::ToggleSlim => self.slim = !self.slim,
            Action::TogglePause => self.paused = !self.paused,
            Action::Help => self.popup = Popup::Help { scroll: 0 },
            Action::ClosePopup => self.popup = Popup::None,
            Action::Up => self.move_by(-1),
            Action::Down => self.move_by(1),
            Action::PageUp => self.move_by(-page),
            Action::PageDown => self.move_by(page),
            Action::Home => self.move_to(0),
            Action::End => self.move_to(usize::MAX),
            Action::Select(i) => {
                if i < self.rows().len() {
                    self.move_to(i);
                }
            }
            Action::OpenChartMenu => {
                self.popup = Popup::ChartMenu {
                    index: mode_index(self.chart),
                };
            }
            Action::MenuMove(delta) => {
                if let Popup::ChartMenu { index } = &mut self.popup {
                    let last = CHART_MODES.len() as i64 - 1;
                    let next = (*index as i64 + i64::from(delta)).clamp(0, last);
                    *index = usize::try_from(next).unwrap_or(0);
                }
            }
            Action::MenuChoose => {
                if let Popup::ChartMenu { index } = self.popup {
                    self.chart = CHART_MODES[index.min(CHART_MODES.len() - 1)];
                    self.popup = Popup::None;
                }
            }
            Action::MenuPick(i) => {
                if let Some(mode) = CHART_MODES.get(i) {
                    self.chart = *mode;
                    self.popup = Popup::None;
                }
            }
            Action::Scroll(Pane::Table, delta) => self.move_by(delta),
            Action::Scroll(Pane::Dashboard, delta) => {
                self.dashboard_scroll =
                    step(self.dashboard_scroll, delta, self.areas.dashboard_max_scroll);
            }
            Action::Scroll(Pane::Inspector, delta) => {
                self.inspector_scroll =
                    step(self.inspector_scroll, delta, self.areas.inspector_max_scroll);
            }
            Action::Scroll(Pane::Help, delta) => {
                if let Popup::Help { scroll } = &mut self.popup {
                    *scroll = step(*scroll, delta, self.areas.help_max_scroll);
                }
            }
        }
    }

    fn move_by(&mut self, delta: i32) {
        let n = self.rows().len();
        if n == 0 {
            return;
        }
        let base = self
            .selected
            .as_deref()
            .and_then(|k| self.rows().iter().position(|r| r.key() == k))
            .unwrap_or(self.cursor.min(n - 1));
        let next = (base as i64 + i64::from(delta)).clamp(0, n as i64 - 1);
        self.move_to(usize::try_from(next).unwrap_or(0));
    }

    fn move_to(&mut self, index: usize) {
        let key = {
            let rows = self.rows();
            if rows.is_empty() {
                return;
            }
            let i = index.min(rows.len() - 1);
            (i, rows[i].key())
        };
        if self.selected.as_deref() != Some(key.1.as_str()) {
            self.inspector_scroll = 0;
        }
        self.cursor = key.0;
        self.selected = Some(key.1);
    }
}
```

```rust
/// The device box's lines for every GPU; `term_width` sizes the VRAM bar as Python does.
pub fn device_lines(app: &App, term_width: u16) -> Vec<Line<'static>> {
    if app.snapshots.is_empty() {
        return vec![Line::from("Sampling GPU counters...")];
    }
    let multi = app.multi();
    let mut out = Vec::new();
    for (i, s) in app.snapshots.iter().enumerate() {
        if multi {
            out.push(Line::styled(format!("GPU {i}"), bold()));
        }
        out.extend(device(app, s, term_width));
    }
    out
}

fn device(app: &App, s: &Snapshot, term_width: u16) -> Vec<Line<'static>> {
    let nv = s.device.as_ref();
    let mut lines = vec![head(app, s, nv)];
    lines.extend(vram(s, term_width));
    if let Some(d) = nv {
        lines.push(metrics_line(d));
        lines.push(status_line(d, app.slim));
    }
    lines
}

fn head(app: &App, s: &Snapshot, nv: Option<&DeviceTelemetry>) -> Line<'static> {
    let name = s
        .adapter
        .as_ref()
        .map(|a| a.name.clone())
        .or_else(|| nv.map(|d| d.name.clone()))
        .unwrap_or_else(|| "GPU".to_string());
    let mut spans = vec![Span::styled(name, bold())];
    if !app.slim {
        let mut info = String::new();
        if let Some(d) = s.driver.as_deref().filter(|d| !d.is_empty()) {
            info.push_str(&format!("   driver {d}"));
        }
        if let Some(c) = s.cuda.as_deref().filter(|c| !c.is_empty()) {
            info.push_str(&format!("  CUDA {c}"));
        }
        spans.push(Span::raw(format!("{info}  ")));
        spans.push(Span::styled(

            fg(YELLOW).add_modifier(Modifier::BOLD),

        spans.push(Span::raw(format!(

    }
    if app.paused {

            fg(RED).add_modifier(Modifier::BOLD),

/// The VRAM bar and its legend. Only measured row bytes are summed (rule 1); rows whose VRAM is
/// unknown leave their share in "unattributed".
fn vram(s: &Snapshot, term_width: u16) -> Vec<Line<'static>> {
    let mut by_kind: Vec<(String, MeasuredTotal)> = Vec::new();
    let mut all = MeasuredTotal::new();
    for r in &s.procs {
        if let Some(m) = r.gpu.vram.as_measured() {
            match by_kind.iter_mut().find(|(k, _)| *k == r.kind) {
                Some((_, total)) => total.add(m),
                None => {
                    let mut total = MeasuredTotal::new();
                    total.add(m);
                    by_kind.push((r.kind.clone(), total));
                }
            }
            all.add(m);
        }
    }
    let mut order: Vec<(String, f64)> = by_kind
        .into_iter()
        .map(|(k, t)| (k, t.total() as f64))
        .collect();
    order.sort_by(|a, b| b.1.total_cmp(&a.1)); // stable: ties keep first-seen order
    let attributed = all.total() as f64;
    let used = s.vram_used.value().map(|u| u as f64);
    let total = s.vram_total.value().map(|t| t as f64);
    let scale = match used {
        Some(u) if attributed > 0.0 => (u / attributed).min(1.0),
        _ => 1.0,
    };
    let mut parts: Vec<(f64, ratatui::style::Color)> = match used {
        Some(_) => order.iter().map(|(k, v)| (v * scale, bar_color(k))).collect(),
        None => Vec::new(),
    };
    let other = used.map_or(0.0, |u| (u - attributed * scale).max(0.0));
    parts.push((other, GREY35));
    let width = usize::from(term_width.saturating_sub(40).clamp(20, 90));
    let mut bar = vec![Span::raw("VRAM ")];
    bar.extend(stacked_bar(&parts, total.unwrap_or(0.0), width));
    bar.push(Span::styled(
        format!(
            " {} / {}",
            used.map_or_else(|| "N/A".to_string(), gb),
            total.map_or_else(|| "N/A".to_string(), gb)
        ),
        bold(),
    ));

    let mut legend = vec![Span::raw("     ")];
    for (k, v) in order.iter().take(7) {
        legend.push(Span::styled("■ ", fg(bar_color(k))));
        legend.push(Span::raw(format!("{k} {}  ", gb(*v))));
    }
    if other > (32 * MIB) as f64 {
        legend.push(Span::styled("■ ", fg(GREY35)));
        legend.push(Span::raw(format!("unattributed {}  ", gb(other))));
    }
    if let (Some(u), Some(t)) = (used, total) {
        legend.push(Span::styled(format!("free {}", gb((t - u).max(0.0))), fg(GREY62)));
    }
    if let Some(shared) = s.shared_used.value().filter(|v| *v > 64 * MIB) {
        legend.push(Span::styled(
            format!("   shared(RAM) {}", gb(shared as f64)),
            fg(YELLOW),
        ));
    }
    if scale < 1.0 {
        legend.push(Span::styled("   [bar normalized; labels are raw]", fg(GREY62)));
    }
    let mut lines = vec![Line::from(bar), Line::from(legend)];
    for note in &s.notes {
        lines.push(Line::styled(format!("     {note}"), fg(GREY62)));
    }
    if let Some(p) = s.process_status.as_deref().filter(|p| !p.is_empty()) {
        lines.push(Line::styled(format!("     DRM process scan: {p}."), fg(GREY62)));
    }
    lines
}

            format!("  Mem activity {}", metric(d.util_mem, None, "%")),
            fg(Chart::MemActivity.color()),

            "  PCIe↓{:>5} ↑{:>4} MB/s",
```

```rust
//! GPU, and the scale notes.
use gputaskman_core::collector::Snapshot;
use gputaskman_core::report::metric;

fn first_is_amd(app: &App) -> bool {
    app.snapshots.first().is_some_and(is_amd)
}

/// The selector's text: `All charts` or the chosen chart's name.
pub fn selector_label(app: &App) -> String {
    match app.chart {
        None => "All charts".to_string(),
        Some(c) => c.menu_name(first_is_amd(app), app.multi()).to_string(),
    }

/// Width of `[<label> ▾]`.
pub fn selector_width(app: &App) -> u16 {
    u16::try_from(selector_label(app).chars().count() + 4).unwrap_or(u16::MAX)
}

/// The chart menu's entries, in `CHART_MODES` order.
pub fn menu_entries(app: &App) -> Vec<String> {
    let (amd, multi) = (first_is_amd(app), app.multi());
    CHART_MODES
        .iter()
        .map(|m| match m {
            None => "All charts".to_string(),
            Some(c) => c.menu_name(amd, multi).to_string(),
        })
        .collect()
}

/// Python's grid: at most 3 columns, one per 46 cells of width (after 6 for border and padding).
pub fn grid_columns(count: usize, term_width: u16) -> usize {
    let width = usize::from(term_width.saturating_sub(6).max(1));
    count.min(3).min(((width + 2) / 46).max(1)).max(1)
}

pub fn chart_lines(app: &App, term_width: u16) -> Vec<Line<'static>> {
    let mut out = vec![Line::from(vec![
        Span::styled(LABEL, bold()),
        Span::styled(format!("[{} ▾]", selector_label(app)), fg(CYAN)),
        Span::styled(HINT, fg(GREY62)),
    ])];
    if app.snapshots.is_empty() {
        return out;
    }
    let multi = app.multi();
    let charts: Vec<Chart> = match app.chart {
        None => CHARTS.to_vec(),
        Some(c) => vec![c],
    };
    let columns = grid_columns(charts.len(), term_width);
    let width = usize::from(term_width.saturating_sub(6).max(1));
    let cell_width = (width.saturating_sub(2 * (columns - 1)) / columns).max(1);
    let empty = History::default();
    let mut notes = Vec::new();
    for (i, s) in app.snapshots.iter().enumerate() {
        let history = app.histories.get(i).unwrap_or(&empty);
        let amd = is_amd(s);
        if multi {
            out.push(Line::styled(format!("GPU {i}"), bold()));
        }
        let cells: Vec<Vec<Span<'static>>> = charts
            .iter()
            .map(|c| cell(*c, history, s, amd, cell_width))
            .collect();
        for chunk in cells.chunks(columns) {
            let mut spans = Vec::new();
            for (j, c) in chunk.iter().enumerate() {
                if j > 0 {
                    spans.push(Span::raw("  "));
                }
                spans.extend(c.iter().cloned());
            }
            out.push(Line::from(spans));
        }
        let note = note(history, s, amd);
        notes.push(if multi { format!("GPU {i}: {note}") } else { note });
    }
    for n in notes {
        out.push(Line::styled(n, fg(GREY62)));
    }
    out
}

fn cell(c: Chart, h: &History, s: &Snapshot, amd: bool, width: usize) -> Vec<Span<'static>> {
    let style = fg(c.color());
    let name = format!("{:<12} ", c.name(amd));
    let value = format!("{:>8} ", metric(h.current(c), Some(0), c.unit()));
    let line = spark(
        h.values(c),
        width.saturating_sub(22).max(1),
        h.scale(c, s.device.as_ref()),
    );
    let used = name.chars().count() + value.chars().count() + line.chars().count();
    let mut spans = vec![
        Span::styled(name, style),
        Span::styled(value, style.add_modifier(Modifier::BOLD)),
        Span::styled(line, style),
    ];
    if used < width {
        spans.push(Span::raw(" ".repeat(width - used)));
    }
    spans
}

fn note(h: &History, s: &Snapshot, amd: bool) -> String {
    let d = s.device.as_ref();
    format!(
        "Recent samples · blank = no reading · power 0–{:.0} W · {} clock 0–{:.0} MHz",
        h.scale(Chart::Power, d),
        if amd { "GFX" } else { "SM" },
        h.scale(Chart::Clock, d)
    )
}
```

```rust
//! The process table (`app.py` `render_table`): cells per row, in Python's columns and colours.
use gputaskman_core::model::Engines;
use gputaskman_core::provenance::{Bytes, Reason};
use gputaskman_core::report::vram_label;
use ratatui::style::{Modifier, Style};

use crate::app::App;
use crate::format::{
    GREY62, GREY70, MAGENTA, MIB, RED, YELLOW, bold, bytes_cell, fg, kind_style, pct_cell,
};
use crate::rows::{SORTS, ShownRow};

/// Name, width (0 fills the rest), right-aligned.
pub const COLUMNS: [(&str, u16, bool); 12] = [
    ("PID", 8, true),
    ("Process", 22, false),
    ("Kind", 11, false),
    ("Runtime", 20, false),
    ("VRAM", 10, true),
    ("Spill", 9, true),
    ("Paged", 9, true),
    ("GPU%", 5, true),
    ("3D", 4, true),
    ("Copy", 5, true),
    ("Video", 6, true),
    ("What's inside", 0, false),
];

/// The extra column with several GPUs.
pub const GPU_COLUMN: (&str, u16, bool) = ("GPU", 3, true);

pub fn subtitle(app: &App) -> String {
    format!(
        "sort: {}  ·  {} processes",
        SORTS[app.sort % SORTS.len()],
        if app.show_all { "all" } else { "top" }
    )
}

pub fn cells(r: &ShownRow<'_>, multi: bool) -> Vec<(String, Style)> {
    let row = r.row;
    let g = &row.gpu;
    let local = row.origin == gputaskman_core::collector::Origin::Local;
    let engine = |f: &dyn Fn(&Engines) -> f64| match &g.engines {
        e @ Engines::Measured { .. } => pct_cell(Some(f(e))),
        Engines::Unavailable { .. } => pct_cell(None),
    };

    let spill_text = bytes_cell(&g.shared, MIB);
    let spill_style = if spill_text == "n/a" {
        fg(GREY62)
    } else if g.shared.value().is_some_and(|v| v >= 256 * MIB)
        && matches!(row.kind.as_str(), "LLM" | "AI")
        && r.snap.shared_is_spill
    {
        fg(RED).add_modifier(Modifier::BOLD)
    } else {
        fg(YELLOW)
    };
    // Ruling R4: no committed counter means no paged estimate at all.
    let paged = match g.committed {
        Bytes::Unavailable {
            reason: Reason::NotOnBackend,
        } => String::new(),
        _ => bytes_cell(&g.paged_out(), MIB),
    };

    let mut out = vec![
        (
            row.pid_label(),
            if local { Style::new() } else { fg(GREY62) },
        ),
        (row.name.clone(), Style::new()),
        (row.kind.clone(), kind_style(&row.kind)),
        (
            row.detail
                .runtimes
                .iter()
                .take(3)
                .cloned()
                .collect::<Vec<_>>()
                .join(" "),
            fg(GREY70),
        ),
        (
            vram_label(g),
            if g.vram.is_measured() { bold() } else { fg(GREY62) },
        ),
        (spill_text, spill_style),
        (paged, fg(GREY62)),
        engine(&|e| e.busiest().unwrap_or(0.0)),
        engine(&|e| e.get("3d") + e.get("compute")),
        engine(&|e| e.get("copy")),
        engine(&|e| e.get("decode") + e.get("encode") + e.get("video")),
        (
            row.inside(),
            fg(if row.llm.is_some() { MAGENTA } else { GREY62 }),
        ),
    ];
    if multi {
        out.push((r.gpu.map_or_else(String::new, |i| i.to_string()), Style::new()));
    }
    out
}

/// The text of `column` in the visible row `key` (for tests).
pub fn cell(app: &App, key: &str, column: &str) -> Option<String> {
    let multi = app.multi();
    let index = COLUMNS
        .iter()
        .map(|c| c.0)
        .chain(multi.then_some(GPU_COLUMN.0))
        .position(|c| c == column)?;
    let rows = app.rows();
    let row = rows.iter().find(|r| r.key() == key)?;
    cells(row, multi).into_iter().nth(index).map(|c| c.0)
}
```

```rust
fn basename(path: &str) -> String {
    Path::new(path)
        .file_name()
        .map_or_else(|| path.to_string(), |n| n.to_string_lossy().into_owned())
}

pub fn title(app: &App) -> String {
    let Some(r) = app.selected_row() else {
        return String::new();
    };
    let row = r.row;
    let host = if row.origin == Origin::Outside { "host PID " } else { "" };
    let mut t = format!("{} ({host}{}) - {}", row.name, row.pid, row.kind);
    if let Some(i) = r.gpu {
        t.push_str(&format!(" - GPU {i}"));
    }
    t
}

pub fn lines(app: &App, term_width: u16) -> Vec<Line<'static>> {
    let Some(r) = app.selected_row() else {
        return vec![Line::styled(PROMPT, fg(GREY62))];
    };
    let mut out = vec![header(&r)];
    out.extend(provenance_notes(r.row, r.snap));
    out.extend(handy_lines(r.row));
    match &r.row.llm {
        Some(v) => out.extend(llm_lines(&r, v, term_width)),
        None => out.extend(other_lines(r.row)),
    }
    let detail = &r.row.detail;
    if !detail.ports.is_empty() {
        let ports: Vec<String> = detail.ports.iter().take(8).map(u16::to_string).collect();
        out.push(Line::styled(format!("listening: {}", ports.join(", ")), fg(GREY50)));
    }
    if !detail.cmdline.is_empty() {
        let cmd: String = detail.cmdline.join(" ").chars().take(400).collect();
        out.push(Line::styled(cmd, fg(GREY42)));
    } else if detail.access_denied {
        out.push(Line::styled(
            "(protected process - run elevated for runtime/file details)",
            fg(GREY42),
        ));
    }
    out
}

fn header(r: &ShownRow<'_>) -> Line<'static> {
    let g = &r.row.gpu;
    let drm_local = r.snap.backend == Some(BackendKind::Drm) && r.row.origin == Origin::Local;
    // Ruling R5: rows without a spill counter print n/a here, as Python does.
    let spill = if drm_local {
        g.shared.value().map_or_else(|| "n/a".to_string(), |v| gb(v as f64))
    } else {
        "n/a".to_string()
    };
    let spill_style = if r.snap.shared_is_spill && g.shared.value().is_some_and(|v| v > 256 << 20)
    {
        fg(RED).add_modifier(Modifier::BOLD)
    } else {
        Style::new()
    };
    let engines = match &g.engines {
        Engines::Measured { by_engine } => {
            let busy: Vec<String> = by_engine
                .iter()
                .filter(|(_, v)| **v >= 0.5)
                .map(|(k, v)| format!("{k} {v:.0}%"))
                .collect();
            if busy.is_empty() { "idle".to_string() } else { busy.join(" ") }
        }
        Engines::Unavailable { .. } => "n/a".to_string(),
    };
    let mut spans = vec![
        Span::styled("VRAM ", bold()),
        Span::styled(vram_label(g), bold()),
        Span::raw("   spill(RAM) "),
        Span::styled(spill, spill_style),
        Span::raw("   paged(est) n/a"),
        Span::raw(format!("   engines {engines}")),
    ];
    if !r.row.detail.runtimes.is_empty() {
        spans.push(Span::styled("   runtime ", fg(GREY62)));
        spans.push(Span::styled(r.row.detail.runtimes.join(" "), fg(CYAN)));
    }
    Line::from(spans)
}

fn owner_note(owner: Option<Confidence>) -> &'static str {
    if owner == Some(Confidence::Order) { ORDER_NOTE } else { INFERRED_NOTE }
}

fn provenance_notes(row: &ProcRow, s: &Snapshot) -> Vec<Line<'static>> {
    let g = &row.gpu;
    let local = row.origin == Origin::Local;
    let drm = s.backend == Some(BackendKind::Drm);
    let mut out = Vec::new();
    if local && g.vram.is_measured() && g.owner.is_some() {
        out.push(Line::styled(owner_note(g.owner), fg(GREY62)));
    }
    if local && !g.vram.is_measured() {
        if let Bytes::Inferred { by, .. } = g.vram {
            out.push(Line::styled(owner_note(Some(by)), fg(GREY62)));
        } else if drm && let Some(note) = drm_note(g) {
            out.push(Line::styled(note, fg(GREY62)));
        }
    }
    if drm && local && let Some(res) = &g.resident {
        let size = |b: Bytes| b.value().map_or_else(|| "n/a".to_string(), |v| gb(v as f64));
        out.push(Line::styled(
            format!(
                "Resident VRAM {}, GTT {}. {DRM_RESIDENT_NOTE}",
                size(res.vram),
                size(res.gtt)
            ),
            fg(GREY62),
        ));
    }
    if drm && g.kfd {
        out.push(Line::styled(KFD_NOTE, fg(GREY62)));
    }
    out
}

fn file_line(m: &MappedModel, color: ratatui::style::Color, prefix: &str, evidence: bool) -> Line<'static> {

fn llm_lines(r: &ShownRow<'_>, v: &LlmView, term_width: u16) -> Vec<Line<'static>> {
    let mut out = Vec::new();
    if r.gpu.is_some() {
        out.push(Line::styled(
            "Model files, launch flags and runtime buffer logs can span GPUs. The breakdown below is not a measured per-device model placement.",
            fg(GREY70),
        ));
    }
    let width = usize::from(term_width.saturating_sub(8).clamp(20, 100));
    let seg_total: u64 = v.segments.iter().filter_map(|x| x.bytes.value()).sum();
    let shown = r.row.gpu.shown_vram().map_or(0, |s| s.get());
    let total = shown.max(seg_total).max(1) as f64;
    let parts: Vec<_> = v
        .segments
        .iter()
        .map(|x| (x.bytes.value().unwrap_or(0) as f64, segment_color(x.kind)))
        .collect();
    out.push(Line::from(stacked_bar(&parts, total, width)));
    let mut legend = Vec::new();
    for x in &v.segments {
        legend.push(Span::styled("■ ", fg(segment_color(x.kind))));
        let exact = matches!(x.bytes, Bytes::Reported { .. });
        legend.push(Span::styled(
            format!("{} {}", x.label, x.bytes.value().map_or_else(|| "n/a".to_string(), |b| gb(b as f64))),
            if exact { bold() } else { Style::new() },
        ));
        legend.push(Span::raw("  "));
    }
    if let Some(src) = &v.log_source {
        legend.push(Span::styled(format!("(allocated sizes from {})", basename(src)), fg(GREEN)));
    }
    out.push(Line::from(legend));
    if !v.models.is_empty() {
        out.extend(model_table(v));
    }
    for f in &v.other_files {
        out.push(file_line(f, GREY62, "file: ", true));
    }
    if let Some(sv) = &v.server {
        let mut spans = vec![Span::styled("server ", bold()), Span::styled(format!("{} {}", sv.kind, sv.url), fg(CYAN))];
        if let Some(n) = sv.n_ctx.filter(|n| *n > 0) {
            spans.push(Span::raw(format!("  ctx {}", thousands(n.unsigned_abs()))));
        }
        if let Some(total) = sv.slots_total {
            spans.push(Span::raw(format!(
                "  slots busy {}/{total}",
                sv.slots_busy.map_or_else(|| "?".to_string(), |b| b.to_string())
            )));
        }
        if let Some(g) = sv.gen_tok_s.filter(|g| *g != 0.0) {
            spans.push(Span::styled(format!("  gen {g:.1} tok/s"), fg(GREEN).add_modifier(Modifier::BOLD)));
        }
        if let Some(p) = sv.prompt_tok_s.filter(|p| *p != 0.0) {
            spans.push(Span::raw(format!("  prompt {p:.0} tok/s")));
        }
        out.push(Line::from(spans));
        if sv.kind == "lmstudio" {
            for m in sv.models.iter().take(4) {
                out.push(Line::raw(format!(
                    "  loaded: {} {} {} ctx {}",
                    m.name.as_deref().unwrap_or(""),
                    m.r#type.as_deref().unwrap_or(""),
                    m.quant.as_deref().unwrap_or(""),
                    m.ctx.map_or_else(|| "?".to_string(), |c| c.to_string())
                )));
            }
        }
    }
    for n in &v.notes {
        let style = if n.starts_with('!') { fg(RED).add_modifier(Modifier::BOLD) } else { fg(GREY70) };
        out.push(Line::styled(format!("• {n}"), style));
    }
    out
}

/// The model table, columns padded to their widest cell and separated by two spaces.
fn model_table(v: &LlmView) -> Vec<Line<'static>> {
    let headers = ["", "model", "arch", "params", "quant", "layers", "train ctx", "on GPU (est)", "evidence", "file"];
    let mut rows: Vec<[String; 10]> = Vec::new();
    for (i, g) in v.models.iter().enumerate() {
        let f = v.files.get(i);
        rows.push([
            v.kind_label(i),
            v.label(i),
            g.arch().to_string(),
            g.params_label(),
            g.quant(),
            if g.n_layers() == 0 { String::new() } else { g.n_layers().to_string() },
            g.ctx_train().filter(|c| *c != 0).map_or_else(String::new, thousands),
            gb(g.gpu_weight_bytes(None) as f64),
            f.map_or_else(String::new, MappedModel::evidence_label),
            basename(&g.path),
        ]);
    }
    let mut widths = headers.map(|h| h.chars().count());
    for r in &rows {
        for (w, c) in widths.iter_mut().zip(r) {
            *w = (*w).max(c.chars().count());
        }
    }
    let pad = |s: &str, w: usize| format!("{s:<w$}");
    let mut out = vec![Line::styled(
        headers.iter().zip(widths).map(|(h, w)| pad(h, w)).collect::<Vec<_>>().join("  "),
        fg(GREY70).add_modifier(Modifier::BOLD),
    )];
    let styles = [fg(MAGENTA), Style::new(), Style::new(), Style::new(), Style::new(), Style::new(), Style::new(), Style::new(), fg(GREEN), fg(GREY50)];
    for r in rows {
        let mut spans = Vec::new();
        for (j, ((c, w), st)) in r.iter().zip(widths).zip(styles).enumerate() {
            if j > 0 {
                spans.push(Span::raw("  "));
            }
            spans.push(Span::styled(pad(c, w), st));
        }
        out.push(Line::from(spans));
    }
    out
}

fn other_lines(row: &ProcRow) -> Vec<Line<'static>> {
    let mut out = vec![Line::styled(explain(&row.kind), fg(GREY70))];
    for m in &row.detail.models {
        out.push(file_line(m, MAGENTA, "file: ", true));
    }
    if !row.detail.candidates.is_empty() {
        out.push(Line::styled(
            "No mapped model file was observed. Some runtimes read then close model files. Installed candidates (not proven loaded):",
            fg(GREY70),
        ));
        for m in &row.detail.candidates {
            out.push(file_line(m, GREY62, "  ", false));
        }
    }
    out
}
```

```rust
/// One markdown line: `**bold**`, `*italic*` and `` `code` `` become styled spans.
fn inline(text: &str) -> Line<'static> {
    let mut spans = Vec::new();
    let mut buf = String::new();
    let (mut strong, mut em, mut code) = (false, false, false);
    let style = |strong: bool, em: bool, code: bool| {
        let mut s = if code { fg(CYAN) } else { Style::new() };
        if strong {
            s = s.add_modifier(Modifier::BOLD);
        }
        if em {
            s = s.add_modifier(Modifier::ITALIC);
        }
        s
    };
    let mut rest = text;
    while let Some(c) = rest.chars().next() {
        let marker = if code {
            (c == '`').then_some(1)
        } else if rest.starts_with("**") {
            Some(2)
        } else if c == '`' || c == '*' {
            Some(1)
        } else {
            None
        };
        match marker {
            Some(len) => {
                if !buf.is_empty() {
                    spans.push(Span::styled(std::mem::take(&mut buf), style(strong, em, code)));
                }
                match (len, c) {
                    (2, _) => strong = !strong,
                    (_, '`') => code = !code,
                    _ => em = !em,
                }
                rest = &rest[len..];
            }
            None => {
                buf.push(c);
                rest = &rest[c.len_utf8()..];
            }
        }
    }
    if !buf.is_empty() {
        spans.push(Span::styled(buf, style(strong, em, code)));
    }
    Line::from(spans)
}

fn table_lines(rows: &[Vec<String>]) -> Vec<Line<'static>> {
    let clean = |s: &str| s.replace("**", "").replace('`', "");
    let cells: Vec<Vec<String>> = rows.iter().map(|r| r.iter().map(|c| clean(c)).collect()).collect();
    let columns = cells.iter().map(Vec::len).max().unwrap_or(0);
    let widths: Vec<usize> = (0..columns)
        .map(|i| cells.iter().filter_map(|r| r.get(i)).map(|c| c.chars().count()).max().unwrap_or(0))
        .collect();
    cells
        .iter()
        .enumerate()
        .map(|(n, r)| {
            let text = r
                .iter()
                .zip(&widths)
                .map(|(c, w)| format!("{c:<w$}"))
                .collect::<Vec<_>>()
                .join("  ");
            if n == 0 { Line::styled(text, bold()) } else { Line::raw(text) }
        })
        .collect()
}

pub fn help_lines() -> Vec<Line<'static>> {
    let mut out = Vec::new();
    let mut table: Vec<Vec<String>> = Vec::new();
    for raw in HELP.lines() {
        if raw.starts_with('|') {
            if !raw.contains("---") {
                table.push(raw.trim_matches('|').split('|').map(|c| c.trim().to_string()).collect());
            }
            continue;
        }
        if !table.is_empty() {
            out.extend(table_lines(&table));
            table.clear();
        }
        match raw.strip_prefix("# ") {
            Some(h) => out.push(Line::styled(
                h.to_string(),
                bold().add_modifier(Modifier::UNDERLINED),
            )),
            None => out.push(inline(raw)),
        }
    }
    if !table.is_empty() {
        out.extend(table_lines(&table));
    }
    out
}
```

```rust
/// A rounded, padded box around wrapped lines, and the rows it needs at `width`.
fn boxed(lines: Vec<Line<'static>>, title: String, width: u16, border: ratatui::style::Color) -> (Paragraph<'static>, u16) {
    let text = Paragraph::new(lines).wrap(Wrap { trim: false });
    let height = u16::try_from(text.line_count(width.saturating_sub(4).max(1))).unwrap_or(u16::MAX).saturating_add(2);
    let block = Block::bordered()
        .border_type(BorderType::Rounded)
        .border_style(fg(border))
        .padding(Padding::horizontal(1))
        .title(title);
    (text.block(block), height)
}

/// Paints content `content_height` rows tall off-screen and copies rows `scroll..` into `area`.
fn render_scrolled(f: &mut Frame, area: Rect, content_height: u16, scroll: u16, paint: impl FnOnce(Rect, &mut Buffer)) {
    let full = Rect::new(0, 0, area.width, content_height.max(area.height));
    let mut tmp = Buffer::empty(full);
    paint(full, &mut tmp);
    let buf = f.buffer_mut();
    for y in 0..area.height {
        for x in 0..area.width {
            buf[(area.x + x, area.y + y)] = tmp[(x, y + scroll)].clone();
        }
    }
}

pub fn draw(app: &App, f: &mut Frame) -> Areas {
    let area = f.area();
    let mut areas = Areas::default();
    if area.width < MIN_WIDTH || area.height < MIN_HEIGHT {
        f.render_widget(Paragraph::new("terminal too small"), area);
        return areas;
    }
    let width = area.width;

    let (device, device_h) = boxed(header::device_lines(app, width), header::device_title(app).to_string(), width, ACCENT);
    let (charts, charts_h) = boxed(charts::chart_lines(app, width), String::new(), width, GREY50);
    let dash_content = device_h.saturating_add(charts_h);
    let dash_h = dash_content.min(area.height / 2);

    let (inspector, inspector_h) = boxed(inspector::lines(app, width), inspector::title(app), width, GREY50);
    let inspector_h = inspector_h.min(area.height * 3 / 10).max(3);

    let [dash, table_area, insp, footer_area] = Layout::vertical([
        Constraint::Length(dash_h),
        Constraint::Min(4),
        Constraint::Length(inspector_h),
        Constraint::Length(1),
    ])
    .areas(area);

    // Dashboard: a scroll view over the two boxes.
    areas.dashboard = dash;
    areas.dashboard_max_scroll = dash_content.saturating_sub(dash.height);
    let scroll = app.dashboard_scroll.min(areas.dashboard_max_scroll);
    render_scrolled(f, dash, dash_content, scroll, |full, buf| {
        device.render(Rect { height: device_h, ..full }, buf);
        charts.render(Rect { y: device_h, height: charts_h, ..full }, buf);
    });
    // The selector sits on the charts box's first content row, after its label.
    let selector_row = i32::from(device_h) + 1 - i32::from(scroll);
    if (0..i32::from(dash.height)).contains(&selector_row) {
        let label = u16::try_from(charts::LABEL.chars().count()).unwrap_or(0);
        areas.chart_selector = Rect::new(

            dash.y + u16::try_from(selector_row).unwrap_or(0),

        )

    }

    areas.table_body = body;
    areas.table_offset = offset;

    areas.inspector = insp;
    let inner_rows = insp.height.saturating_sub(2);
    let content_rows = u16::try_from(
        Paragraph::new(inspector::lines(app, width))
            .wrap(Wrap { trim: false })
            .line_count(width.saturating_sub(4).max(1)),
    )
    .unwrap_or(u16::MAX);
    areas.inspector_max_scroll = content_rows.saturating_sub(inner_rows);
    f.render_widget(inspector.scroll((app.inspector_scroll.min(areas.inspector_max_scroll), 0)), insp);

    areas.footer_hints = footer::draw(f, footer_area);

    match app.popup {
        Popup::None => {}
        Popup::Help { scroll } => areas.help_max_scroll = help::draw(app, f, area, scroll),
        Popup::ChartMenu { index } => {

            let h = u16::try_from(entries.len() + 2).unwrap_or(11);
```

```rust
//! The sampling thread: owns the collectors and sends one snapshot per GPU every interval.
use std::sync::Arc;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::mpsc::{self, Receiver, RecvTimeoutError, Sender};
use std::thread::JoinHandle;
use std::time::Duration;

use gputaskman_core::collector::{Collector, Snapshot};

/// Something that produces a snapshot per call: a `Collector`, or a fake in tests.
pub trait Source: Send {
    fn sample(&mut self) -> Snapshot;
}

impl Source for Collector {
    fn sample(&mut self) -> Snapshot {
        Collector::sample(self)
    }
}

pub struct Sampler {
    stop: Option<Sender<()>>,
    handle: Option<JoinHandle<()>>,
}

/// Waits up to `d`; true when told to stop (a message or a dropped sender).
fn stop_requested(rx: &Receiver<()>, d: Duration) -> bool {
    !matches!(rx.recv_timeout(d), Err(RecvTimeoutError::Timeout))
}

impl Sampler {
    pub fn spawn(
        mut sources: Vec<Box<dyn Source>>,
        interval: Duration,
        warmup: Duration,
        paused: Arc<AtomicBool>,
    ) -> (Sampler, Receiver<Vec<Snapshot>>) {
        let (tx, rx) = mpsc::channel();
        let (stop_tx, stop_rx) = mpsc::channel::<()>();
        let handle = std::thread::spawn(move || {
            if stop_requested(&stop_rx, warmup) {
                return;
            }
            loop {
                if !paused.load(Ordering::Relaxed) {
                    let snaps: Vec<Snapshot> = sources.iter_mut().map(|s| s.sample()).collect();
                    if tx.send(snaps).is_err() {
                        return;
                    }
                }
                if stop_requested(&stop_rx, interval) {
                    return;
                }
            }
        });
        (
            Sampler {
                stop: Some(stop_tx),
                handle: Some(handle),
            },
            rx,
        )
    }

    /// Stops the thread and waits for it; `Err` carries a panic's message.
    pub fn join(mut self) -> Result<(), String> {
        self.stop.take();
        match self.handle.take().map(JoinHandle::join) {
            Some(Err(payload)) => Err(payload
                .downcast_ref::<&str>()
                .map(|s| (*s).to_string())
                .or_else(|| payload.downcast_ref::<String>().cloned())
                .unwrap_or_else(|| "the sampling thread stopped".to_string())),
            _ => Ok(()),
        }
    }
}

impl Drop for Sampler {
    fn drop(&mut self) {
        self.stop.take();
        if let Some(h) = self.handle.take() {
            let _ = h.join();
        }
    }
}
```

```rust
//! Raw mode, the alternate screen and mouse capture, undone on every exit path.
use std::io::{self, Stdout};
use std::thread::{self, ThreadId};

use crossterm::cursor::Show;
use crossterm::event::{DisableMouseCapture, EnableMouseCapture};
use crossterm::execute;

use ratatui::Terminal;
use ratatui::backend::CrosstermBackend;

pub type Tui = Terminal<CrosstermBackend<Stdout>>;

pub fn restore() {
    let _ = execute!(io::stdout(), DisableMouseCapture, LeaveAlternateScreen, Show);
    let _ = disable_raw_mode();
}

/// Restores the terminal before a main-thread panic prints. A sampler-thread panic is reported by
/// `run` after the terminal is restored, so its default message is suppressed.
fn install_panic_hook(main: ThreadId) {
    let previous = std::panic::take_hook();
    std::panic::set_hook(Box::new(move |info| {
        if thread::current().id() == main {
            restore();
            previous(info);
        }
    }));
}

pub struct TerminalGuard;

impl TerminalGuard {
    pub fn enter() -> io::Result<(TerminalGuard, Tui)> {
        install_panic_hook(thread::current().id());
        enable_raw_mode()?;
        let guard = TerminalGuard; // from here on, Drop restores
        execute!(io::stdout(), EnterAlternateScreen, EnableMouseCapture)?;
        let terminal = Terminal::new(CrosstermBackend::new(io::stdout()))?;
        Ok((guard, terminal))
    }
}

impl Drop for TerminalGuard {
    fn drop(&mut self) {
        restore();
    }
}
```

```rust
/// Before the first sample: NVML and DRM engine rates need a baseline (Python waits 0.5 s).
const WARMUP: Duration = Duration::from_millis(500);
/// How often input is checked while nothing arrives.
const POLL: Duration = Duration::from_millis(100);

pub struct Config {
    pub interval: Duration,
}

#[derive(Debug)]
pub enum TuiError {
    Io(std::io::Error),
    /// The sampling thread stopped; the message is its panic's.
    Sampler(String),
}

impl std::fmt::Display for TuiError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            TuiError::Io(e) => write!(f, "terminal error: {e}"),
            TuiError::Sampler(m) => write!(f, "sampling stopped: {m}"),
        }
    }
}

impl std::error::Error for TuiError {}

impl From<std::io::Error> for TuiError {
    fn from(e: std::io::Error) -> Self {
        TuiError::Io(e)
    }
}

/// Runs the TUI until the user quits. `sources` are one collector per GPU, in GPU order.
pub fn run(sources: Vec<Box<dyn Source>>, config: Config) -> Result<(), TuiError> {
    let paused = Arc::new(AtomicBool::new(false));
    let (sampler, rx) = Sampler::spawn(sources, config.interval, WARMUP, Arc::clone(&paused));
    let (guard, mut terminal) = terminal::TerminalGuard::enter()?;
    let result = event_loop(&mut terminal, &rx, &paused);
    drop(guard); // the terminal is normal again before anything is reported
    match result {
        Err(TuiError::Sampler(_)) => Err(TuiError::Sampler(match sampler.join() {
            Err(message) => message,
            Ok(()) => "the sampling thread stopped".to_string(),
        })),
        other => other, // dropping `sampler` stops and joins it
    }
}

fn event_loop(terminal: &mut terminal::Tui, rx: &Receiver<Vec<Snapshot>>, paused: &AtomicBool) -> Result<(), TuiError> {
    let mut app = App::default();
    let mut dirty = true;
    loop {
        loop {
            match rx.try_recv() {
                Ok(snaps) => {
                    app.apply_all(snaps);
                    dirty = true;
                }
                Err(TryRecvError::Empty) => break,
                Err(TryRecvError::Disconnected) => return Err(TuiError::Sampler(String::new())),
            }
        }
        if dirty {
            let mut areas = app.areas;
            terminal.draw(|f| areas = view::draw(&app, f))?;
            app.areas = areas;
            dirty = false;
        }
        if event::poll(POLL)? {
            let action = match event::read()? {
                Event::Key(k) if k.kind == KeyEventKind::Press => action::from_key(k, &app),
                Event::Mouse(m) => action::from_mouse(m, &app),
                Event::Resize(..) => {
                    dirty = true;
                    None
                }
                _ => None,
            };
            if let Some(a) = action {
                app.update(a);
                paused.store(app.paused, Ordering::Relaxed);
                dirty = true;
            }
            if app.quit {
                return Ok(());
            }
        }
    }
}
```

```rust
/// The live TUI: one collector per GPU (or just `--gpu N`), sharing the scan budget.
fn tui_main(cli: &Cli, sys_root: &std::path::Path, proc_root: &std::path::Path) -> i32 {
    if !std::io::stdout().is_terminal() {
        eprintln!("the TUI needs an interactive terminal; use --once or --json");
        return 2;
    }
    let indices: Vec<usize> = match cli.gpu {
        Some(i) => vec![i],
        None => {
            let clock: Arc<dyn Clock> = Arc::new(SystemClock);
            let (backends, _) = linux_backends_at(sys_root, proc_root, clock);
            (0..list_adapters(&backends).len().max(1)).collect()
        }
    };
    let budget = SCAN_BUDGET / u32::try_from(indices.len()).unwrap_or(1).max(1);
    let mut sources: Vec<Box<dyn Source>> = Vec::new();
    for index in indices {
        let clock: Arc<dyn Clock> = Arc::new(SystemClock);
        let (backends, notes) = linux_backends_at(sys_root, proc_root, clock.clone());
        let deps = CollectorDeps {
            backends,
            procs: Box::new(LinuxProcs::new(proc_root.to_path_buf())),
            http: Box::new(UreqGet::default()),
            clock,
            paths: Paths::from_env(),
            notes,
        };
        match Collector::new(deps, index, ScanPolicy::Budgeted(budget)) {
            Ok(c) => sources.push(Box::new(c)),
            Err(e) => return usage_error(&e.to_string()),
        }
    }
    let config = Config {
        interval: Duration::from_secs_f64(cli.interval),
    };
    match gputaskman_tui::run(sources, config) {
        Ok(()) => 0,
        Err(e) => {
            eprintln!("gputaskman: {e}");
            1
        }
    }
}
```
